# roadmap/

Multi-week plans live here, one file per programme. Daily tasks still go through `inbox/`.

Examples you might add later:

- `learning.md` — a four-week skill plan, with session titles and suggested dates
- `health.md` — a training block, written as a plan, not as a medical record
- `setup.md` — anything still left to finish after the 30-minute install

A roadmap is a care plan, not a permission slip. Calendar writes still follow `guardrails.md` and `routines.md`.
