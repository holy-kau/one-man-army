# context/

Longer background than `memory.md`, split by area. If `memory.md` is the front sheet of the case notes, these are the sections behind it. Agents load `me.md` plus only the file for the task at hand. Do not dump your whole life into one file.

The reasoning agent is the sole editor of files in this folder.

Suggested files, once you need them:

- `me.md` — identity, preferences, how you like work to arrive (already started)
- `chief-of-staff.md` — reporting tone, protected calendar blocks, people who may be mentioned in briefs
- `scheduler.md` — working hours, typical shift or freelance patterns, what must never clash
- `learning.md` — current syllabus or skill goals, preferred session length
- `health.md` — training preference, broad constraints, and what this agent must never do
- `lifestyle.md` — travel preferences, social constraints, housing search criteria if any

Write facts, not essays. If a fact is sensitive (health detail, money, someone else's private life), ask whether it belongs here at all. Usually it does not.
