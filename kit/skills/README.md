# skills/

A skill is a written routine an agent can run the same way every time: a standard operating procedure. One folder per skill, each with a `SKILL.md`.

Start with these three. Add your own only when a job has worked by hand at least twice.

| Skill | Run by | Say |
|---|---|---|
| `interview-me` | Reasoning agent | "Interview me about my week" (or my work, my health, my studies) |
| `sunday-audit` | Reasoning agent | "Run the Sunday audit" |
| `new-skill-from-chat` | Reasoning agent | "Make this a skill" |
| `_template` | Anyone | Copy it to start a new skill |

Some tools read skills automatically (for example a `skills` or `.claude/skills` folder). Others need you to paste the skill, or say "follow skills/<name>/SKILL.md". Either works.
