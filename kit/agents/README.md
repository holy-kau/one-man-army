# agents/

One-page role cards. These are reference copies. Paste the "Starter instructions" (and the mission, if your tool has room) into the agent itself: a Project, a custom assistant, a Gem, a Bot, or a pinned first message. `tools.md` shows where instructions go in each tool.

Start with two: **Chief of Staff** and the **reasoning agent**. Add **Research desk** when you have a real question. Add Scheduler, Learning, Health or Lifestyle when you have a repeating job for them.

Every card has the same shape: mission, what it owns, what it never does, instructions to paste. If you add an agent that is not here, write a card in the same shape and add a row to the roster in `AGENTS.md`.

On the ward: Chief of Staff is the ward sister, the reasoning agent is the medical officer, Research desk is the library, and the other cards are specialty nurses.
